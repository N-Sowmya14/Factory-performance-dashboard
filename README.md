# Factory Performance Dashboard

## Project Overview
An Excel-based dashboard designed to track factory production performance and inventory levels. It helps monitor daily production against targets, sales, unsold quantities, and inventory stock status.

## Tools Used
- Microsoft Excel
- Excel formulas: IF, SUM, and basic calculations
- Charts and data visualization
- Conditional formatting and dashboard design

## Key Features
- Daily production versus target analysis
- Target achievement percentage
- Sold and unsold quantity tracking
- Production status: Target Met or Below Target
- Inventory stock monitoring
- Inventory valuation and reorder identification
- Summary dashboard with key metrics

## Key Results
- Total quantity produced: 480 units
- Total quantity sold: 425 units
- Days target met: 2
- Total inventory value: ₹19,690
- Materials requiring reorder: 2

## Project Files
- `Factory_Digital_Transformation.xlsx` — Excel workbook containing Inventory, Production, and Dashboard sheets.

## Learning Outcomes
Practiced Excel formulas, data organization, inventory tracking, chart creation, and dashboard reporting.

*Note: This project uses sample data for learning and demonstration purposes.*
